# 판정 기록 — A31(용인 수지 오피스텔·도생) 도면 쌍, 2026-10-28

입력: 원본 `A31-001~016 전체 평면도.dwg`(+XREF 3개) / 참조 `251215 구조평면도(실시설계).dwg`(동료 수작업 구조도).
명령문: 1단계 노랑=골조·빨강 중심선(벽·기둥만)·OPEN X / 2단계 기둥 중심 거더·인접 기둥만·6m 초과 2등분·BEAM·비지지 표시.

## 공통 규칙으로 반영(코드 수정, v1.1.3)
| 항목 | 판정 | 근거 |
|---|---|---|
| 골조를 레이어명(CON/COL) 대신 **유효색 노랑**으로 | 공통 | 두 프로젝트 모두 노랑=골조. 1차 99.7%, A31 지하·2~4층 100%, 주거층 93~96% |
| 기둥을 닫힌 폴리선뿐 아니라 **4개 선분 직사각형**에서도 | 공통 | A31 기둥 블록은 4개 LINE. 1차 정확도 유지 |
| 중심선 = **일점쇄선(CEN·CENTER) 선종류 또는 CEN/AXIS/GRID 레이어**, 색 불문 | 공통 | 빨강만 보면 단열재·가구 등 찌꺼기 1차 45%→95%; 1차 참조는 빨강 아닌 CEN-1·CEN-PARK 도 포함, A31 참조는 색 15 지하축선 포함 |
| **반복 부품 블록(세대·기둥·기호) 안의 중심선 제외** | 공통 | A31 주거층 참조는 세대 내부 벽 중심선 없음(66→84%). 1차는 영향 없음 |
| OPEN = **OPEN 이름 레이어 전체 + OPEN 문자 둘레 X** | 공통 | 1차 OPEN 86%, A31 100%(B5 59%: 참조 쪽 표기 차이) |
| 층 = 골조 덩어리 + 가장 가까운 `…평면도` 제목, 숫자 없는 층(PIT)은 시트 순서 | 공통 | 1차(세로 띠)·A31(가로 시트) 모두 자동 인식. B6·1~4층·PIT·5~14층 등 15층 |
| XREF 자동 결합 + XCLIP 존중 | 공통 | A31 원본은 XREF 없이는 중심선만 남음 |

## 이 도면(참조) 전용으로 판정 — 코드 미반영
| 참조의 특징 | 판정 | 이유 |
|---|---|---|
| 지하층 구조도에 거더가 거의 없음(무량판, 벽거더·램프 주변 보만) | 도면 전용(설계 선택) | 명령문 2단계는 "기둥과 기둥 사이 GIRDER". 무량판 여부는 구조 설계 판단이라 규칙화 불가 |
| 주거층(5~24층·옥탑) 구조도는 벽식 + S-BEAM(발코니·개구부 작은 보)만 | 도면 전용 | 기둥이 거의 없는 벽식 층. 명령문에는 벽식 처리 규칙 없음 → 전문가 규칙 필요 |
| 2~4층 거더 위치가 기둥 중심에서 최대 ~800mm 벗어남 | 보류 | 명령문은 "기둥 중심 기준". 참조는 축선(그리드)에 맞춘 듯. 150mm 기준 44%, 800mm 기준 86% |
| 2~4층 보 간격·개수(참조 보 재현 42~50%) | 보류 | 참조 베이당 보 2~3개 간격 규칙 확인 필요(현재 4m 초과 베이 2등분, 8.7m 이상 3등분) |
