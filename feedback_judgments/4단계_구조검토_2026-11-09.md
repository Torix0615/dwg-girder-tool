## 전문가 질문지 (그대로 전달용)

4단계(구조 검토) 기능을 만들기 전에 아래 5가지를 확정해 주셔야 합니다. 해당 번호에 ○ 표시하시거나 값을 적어 주시면 됩니다.

**1. 부재력(축력·모멘트·전단력)은 어디서 가져옵니까?**
- ① MIDAS Gen에서 해석한 결과를 파일로 첨부 → 형식(텍스트 출력 / 엑셀 / 기타): ______
- ② 프로그램이 하중값을 받아 직접 계산
- "MGT 파일을 새로 첨부"가 ①을 뜻하는지도 확인 부탁드립니다. (예 / 아니오)

**2. 하중과 하중조합**
- 고정하중: 슬래브 두께 ____ mm, 마감 ____ kN/m², 구조체 자중 자동 포함(예/아니오)
- 활하중: 주차장 ____ kN/m², 그 외 용도 ____ kN/m²
- 검토할 하중조합(예: 1.2D+1.6L, 1.4D, 기타): ______________________

**3. 설계기준과 재료**
- 적용 기준: KDS 14 20(콘크리트구조 강도설계법) (예 / 다른 기준: ______)
- 콘크리트 fck: 기둥 ____ MPa, 보 ____ MPa (현재 MGT는 C27·C35)
- 철근 fy: SD400 / SD500 / 기타 ____
- 사용 철근 직경 후보: D13 D16 D19 D22 D25 D29 D32 중 선택 → ______, 최대 단수 ____
- 피복 두께: 기둥 ____ mm, 보 ____ mm

**4. 검토 범위**
- 기둥 PM 검토: 1축 / 2축(Mx·My 동시), 장주(세장비) 효과 포함(예/아니오)
- 보 검토: 휨(양단·중앙)+전단만 / 처짐·균열·비틀림도 포함

**5. 승인 후 수정 MGT에 쓸 내용**
- 단면 치수(*SECTION)만 변경 / 철근 배근 정보까지 기록
- 철근까지라면 MIDAS가 읽는 설계 데이터 형식 샘플(.mgt 일부)을 보내 주실 수 있습니까? (예/아니오)
