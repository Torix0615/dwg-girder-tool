GirderTool (골조·거더·보 생성기)  Ver 1.4.0 (설치본 1.4.0 + 자동 업데이트)
==========================================

1. 개요
 - 건축 평면도(DWG/DXF)에서 구조 골조(기둥·벽·중심선·OPEN)를 추출하고,
   층별 거더·보를 배치한 DXF와 MIDAS Gen 입력 파일(MGT)을 생성합니다.
 - 모든 도면에 공통인 규칙으로 처리합니다. 설정(⚙)은 모든 도면에 공통인 값만 둡니다.

2. 설치
 - GirderTool-Setup-1.4.0.exe 실행 → 설치 완료 후 트레이에 상주합니다.
 - 업데이트는 자동으로 확인·적용되며, 변경 내용이 화면에 표시됩니다.

3. 사용
 - 화면 구성(v1.7.0): 제목 줄 아래 버튼 줄 = [+ 골조 모델링] [+ 구조 검토] [피드백] … 오른쪽 끝 [피드백 로그].
   그 아래 왼쪽 = 작업 목록(날짜·시간 / 파일 이름 / 상태), 오른쪽 = 고른 작업의 결과 화면.
   왼쪽 목록과 오른쪽 화면 사이의 줄을 끌면 목록 폭이 바뀝니다(170~340, 기본 255, 다음 실행에도 유지).
 - 골조 모델링(1·2·3단계): 도면에서 골조·거더·보 DXF 와 MIDAS GEN MGT 를 만듭니다.
 1) [+ 골조 모델링] → 평면도 DWG 또는 DXF 1개 선택(파일을 창에 끌어다 놓아도 됨)
 2) 진행률 확인 후 완료되면 [결과 DXF]·[MIDAS GEN (MGT)] 다운로드
 3) 결과에 문제가 없으면 오른쪽 화면 아래 "피드백" 의 [건너뛰기], 있으면 내용을 적어 [전송하기]
 - 구조 검토: 수작업을 마친 MIDAS 모델로 따로 시작합니다(9번 참고).
 - 목록의 상태: 모델링 완료 / 검토 완료 · OK n / NG m / 모델링 실패·검토 실패(빨강 = 파일 문제, 안내대로 고쳐 다시 실행) /
   모델링 에러·검토 에러(노랑 = 프로그램 오류, 자동 보고됨).

3-1. 설정 (오른쪽 위 ⚙, 저장하면 다음 작업부터 적용)
 - 골조 모델링 실행 범위: 1단계까지(골조·중심선·OPEN 추출 후 DXF 저장) / 2단계까지(거더·보까지 DXF 저장) /
   3단계까지(MIDAS GEN MGT 까지, 기본). 1·2단계까지면 MGT 는 만들지 않습니다.
 - 보(BEAM) 생성 켬/끔: 끄면 2단계에서 거더만 생성합니다(BEAM·BEAM(GEN) 레이어와 MGT 보 요소 없음).
 - 보 간격 기준(mm, 보 생성이 켜져 있을 때): 보를 두는 기준 거더 길이(기본 4000) /
   보를 두는 최소 베이 폭(3000) / 보 2개(3등분) 기준 베이 폭(8700) / 보 3개(4등분) 기준 베이 폭(14000).
   숫자만 입력, [기본값으로] → 확인 팝업의 [확인] 으로 복원. 왼쪽 목록과 오른쪽 화면의 파일 이름 아래에 적용된 설정("1단계까지 · 보 없음")이 표시됩니다.
 - MIDAS GEN 층고(mm, 3단계까지 실행할 때): 모든 층에 같은 층고(기본 5000). 기둥·벽 높이와 거더·보 z 위치에 적용됩니다.

4. 입력 도면 요건
 - 외부참조(XREF)가 있는 도면은 참조 DWG를 원본과 같은 폴더(또는 XREF 폴더)에 함께 두십시오.
 - 골조: 노랑(ACI 2) 선·폴리선. 기둥은 닫힌 사각 폴리선 또는 4개 선분 사각형.
 - 중심선: 일점쇄선(CENTER 계열) 선종류 또는 CEN / AXIS / GRID 레이어.
 - OPEN: 레이어명에 OPEN 포함 또는 'OPEN' 문자.
 - 도곽: 시트 테두리 직사각형(한 변 20m 이상)을 최우선으로 인식해 도곽당 1개 층으로 처리합니다.
   도곽 밖 도형(블록은 전개 후 조각 단위)은 제외합니다. 도곽이 없으면 골조 덩어리로 층을 나눕니다.
 - 층 이름: 도곽 안의 '…평면도' 제목 문자(지하N층·N층·PIT·옥탑)로 자동 인식.

5. 결과 파일
 - <원본명>_골조거더보.dxf
   · 층별 블록(B1_골조, 1F_골조 등). 원본은 포함되지 않으며 좌표계는 원본과 동일합니다.
     → 원본 위에 INSERT(0,0) 또는 XREF로 겹쳐 확인하십시오.
   · 레이어: 1단계(골조·중심선·OPEN), 2단계(거더·보), 경고,
     중심선 COLUMN(GEN)·GIRDER(GEN)·BEAM(GEN)·WALL(GEN)·WALL(GEN)-GAP(벽 중심선 끊김 강조).
 - <원본명>_MIDAS.mgt
   · MIDAS Gen 텍스트 입력 파일(단위 kN·mm). 재질·단면·층·절점·요소·경계조건 포함.
 - <원본명>_골조거더보_report.txt : 처리 단계별 기록 및 실패 원인.

6. 적용 규칙(요약)
 - 거더: 각 층의 거더·보는 바로 아래층 기둥·벽 위에 배치. 기둥 중심 간 인접 기둥 연결(기둥 1면당 거더 1개),
   벽 구간은 벽면까지, 기둥·벽이 없으면 기존 거더에 T접합.
 - 보: 4m 초과 베이 2등분, 8.7m 이상 3등분. 보가 많이 뻗는 방향=MAIN, 직각=SUB.
   SUB 보는 MAIN 보를 가로지르지 않습니다(기본: MAIN 보와 교차하는 SUB 보 제거).
 - 간섭 없음: 거더·보가 겹치면 우선순위(기둥-기둥 거더 > 기둥-벽 > T접합 > MAIN 보 > SUB 보) 높은 1개만,
   교차하면 낮은 쪽을 교차점에서 분할.
 - 경고 레이어: 비지지 기둥 / 1방향 지지 / 거더 위 지지 위치를 원+문자로 표시.
 - 단면·치수 기본값: 거더 400×700(X)·500×700(Y), 보 400×600, 층고 5,000.

7. 피드백
 - 작업 뒤 피드백: 왼쪽 목록에서 작업을 누름 → 오른쪽 화면 아래 "피드백" → 종류([공통 규칙] / [이 파일에만 해당]) 선택
   → 내용 입력 → [전송하기](내용을 적으면 켜짐). 같은 작업에는 한 번만 보낼 수 있습니다.
   쓰던 내용은 작업마다 저장되어 다른 화면에 다녀와도 남아 있습니다.
 - [건너뛰기]: 결과에 문제가 없어 피드백이 필요 없을 때 누릅니다. 그 작업은 "문제 없음" 으로 표시되고 되돌릴 수 없습니다.
   (구조 검토 작업은 검토가 끝난 뒤에 나옵니다. 다른 결과표로 다시 검토하면 표시가 지워집니다.)
 - 작업 없이 보내는 피드백: 위쪽 [피드백] → 종류([공통 규칙] / [프로그램 화면·기능]) 선택 → 내용 입력 → [전송하기].
   쓰는 도중에 왼쪽 목록이나 위쪽 버튼을 누르면 "작성 중이던 피드백이 삭제됩니다" 팝업이 나옵니다([취소] = 계속 쓰기).
 - [피드백 로그]: 지금까지 보낸 피드백이 왼쪽 목록에 날짜·시간과 제목(작업 뒤 피드백 = 파일 이름, 작업 없이 보낸 피드백 = 첫 문장)으로
   나오고, 누르면 오른쪽에 내용이 나옵니다. [피드백 로그] 를 다시 누르면 작업 목록으로 돌아갑니다.

8. 실행 실패 시
 - 도면 문제(참조 파일 없음, 노란 골조 없음, 손상 파일)는 목록에 "모델링 실패"(빨강)로 나오고 오른쪽 화면에 조치 내용이 표시됩니다.
   파일을 갖춘 뒤 다시 실행하십시오.
 - 그 외 프로그램 오류는 목록에 "모델링 에러"(노랑)로 나오고 보고서·로그·원본이 자동 전송되어 수정에 사용됩니다.

9. 구조 검토 (골조 모델링 없이 단독 실행)
 - 순서: 골조 모델링(1·2·3단계) → MIDAS Gen 에서 수작업(모델 수정·하중·하중조합 입력·해석) → 구조 검토.
   구조 검토는 골조 모델링과 별개로, 수작업을 마친 모델 MGT 와 그 해석 결과표 두 파일만으로 실행합니다.
 - 준비 1) 모델: MIDAS Gen 에서 File → Export → MIDAS Gen MGT File 로 저장한 .mgt
   준비 2) 결과표: Results → Result Tables → Beam → Force 표(Elem·Load·Part·Axial·Shear·Torsion·Moment)를
           텍스트(.txt)·CSV·엑셀(.xlsx) 중 하나로 저장(구형 .xls 는 .xlsx 로 다시 저장). 단위는 표 머리글의 괄호(kN, kN*m 등)에서 읽습니다.
   결과표는 선택한 모델과 요소 번호가 같아야 합니다. 모델을 고쳤다면 모델도 다시 선택하십시오.
 - 실행: 위쪽 [+ 구조 검토](또는 트레이 메뉴의 [구조 검토…]) → 모델 .mgt 선택(.mgt 를 창에 끌어다 놓아도 됨)
   → 오른쪽 화면에 검토 대상(기둥·거더·보 수)과 검토 제외 목록 표시 → [MIDAS 해석 결과표(텍스트·엑셀) 첨부 → 검토 실행].
 - 모델 읽기 규칙: 수직 부재 = 기둥, 수평 부재는 단면명의 G번호 = 거더·B번호 = 보(RG1·-1G1 = 거더, RB1·RaB1 = 보).
   검토 제외: 더미 단면(치수 100mm 미만·Dummy), WG(벽 위 가상 보), 직사각형 RC 가 아닌 단면(H형강·SRC), 벽·판 요소.
   콘크리트 강도는 모델의 재료 등급(C27·C30·C35 등)을 쓰고, 등급을 읽지 못한 재료만 설정값을 씁니다.
 - 골조 모델링 작업의 오른쪽 화면에는 구조 검토가 나오지 않습니다(구조 검토는 수작업 뒤에 [+ 구조 검토] 로 따로 시작).
   v1.5.x 에서 도면 작업으로 검토했던 결과만 "구조 검토 — 이전 검토 결과" 로 남아 엑셀·수정 MGT 를 내려받을 수 있습니다.
 - 검토 내용: 기둥은 축력·PM 상관도(Mx·My 각 축, 장주 효과), 거더·보는 단부(상부근)·중앙(하부근) 휨과 전단을 KDS 14 20 강도설계법으로 검토합니다.
   결과표의 모든 하중(조합)을 검토해 가장 불리한 값으로 D/C 를 냅니다. 개별 하중케이스(D·L)만 있으면 설정의 하중조합으로 조합합니다.
 - NG 부재는 철근(개수→직경, 스터럽 간격→직경) → 폭 → 춤 순으로 OK 가 되는 조합을 추천합니다. [검토 결과 엑셀]: 검토결과·요약·하중 시트.
   검토결과 시트에는 빈 칸이 없습니다. 해당 없는 칸(기둥의 전단 D/C, OK 부재의 추천, 결과표에 없는 요소)은 "-" 로 표시합니다.
   요약 시트의 "결과표에서 읽은 열" 에 축력·전단력·모멘트를 결과표의 어느 열에서 읽었는지 나옵니다.
 - 결과표에서 축력·전단력·모멘트 열을 찾지 못하거나 값이 전부 0 이면 검토 결과를 만들지 않고 멈춥니다.
   (v1.6.0 까지는 CSV 결과표의 머리글을 잘못 읽어 모든 부재가 OK·빈 칸으로 나왔습니다. CSV 로 검토한 결과는 다시 검토하십시오.)
 - [승인 → 수정 MGT 생성]: 치수가 바뀐 부재만 새 단면(C2·G2·B2…)으로 바꾼 MGT 를 만듭니다. 철근은 MGT 에 쓰지 않습니다(엑셀 참조).
   수정 MGT 는 선택한 모델의 단위(KN·M 등)·한글 이름(그룹·단면)·나머지 내용을 그대로 유지합니다.
 - 설정(⚙) "구조 검토": 콘크리트 fck(기둥·보), 철근 fy, 피복, 기둥 주근(예 12-D22)·띠철근(예 D10@300), 거더·보 상/하부근·스터럽,
   추천 철근 직경 후보, 하중조합, 결과표 단위, 추천 증분·상한, 기둥 철근비 최대. 저장하면 다음 검토부터 적용.
 - 결과표 형식을 읽지 못하면 결과표가 첨부된 오류 보고가 자동 전송되고, 형식을 맞춘 업데이트가 자동 설치됩니다.
 - 검토값은 설계 참고용입니다. 구조 인증·납품 계산서는 MIDAS 설계 결과로 확인하십시오.
